# 0005. 工具参数统一明文

- **日期：** 2026-09-07
- **Fork-ADR：** 0005

## 背景与决策

工具参数使用明文，便于同一会话和代理之间切换模型。所有模型采用同一规则，包括 GPT。

- `spawn_agent`、`send_message`、`followup_task` 的 `message` 使用普通字符串 schema；v2 投递统一渲染消息文本并调用 `InterAgentCommunication::new()`。
- `history.search_contents.query`、`notes.search_contents.query`、`notes.append_to_file.text`、`notes.write_file.text` 使用普通字符串 schema；history/notes 后端接收原始明文 JSON 参数。
- 移除工具 schema 的加密标记及其构造方法、history/notes 的加密参数 header。代理消息继续采用现有日志脱敏方式，调用来源不再决定消息内容格式。

本决策只处理工具参数。reasoning content 与 compaction 的服务端加密保持现状；服务端返回内容及旧历史的加密字段读取兼容也保持现状。

## 路径与重应用

- `tools/src/json_schema/types.rs`：工具 schema 类型仅保留通用字段。
- `core/src/tools/handlers/multi_agents_spec.rs`、`multi_agents_v2.rs` 及其子模块：普通字符串参数、统一明文投递。
- `core/src/tools/router.rs`：直接调用的代理消息沿用明文日志脱敏。
- `ext/history-notes/src/tools.rs`、`backend.rs`：普通字符串参数、JSON 透传。

以上路径均相对 `codex-rs/`。同步上游时按这些位置重应用。上游新增任何使用加密参数的工具，采用时都必须同步改为明文参数和明文投递，清理配套的加密标记与请求逻辑，并更新 OVERLAY。此规则适用于所有模型。

## 如何确认

按 ADR 0002，合并后在 `main` 验证：

- `codex-core` lib 测试覆盖 spawn、send_message、followup_task 的明文内容和日志脱敏。
- `multi_agent_v2_spawn_sends_agent_message_to_child` 对不同模型比较子线程收到的完整明文 `agent_message`。
- `installed_extension_exposes_and_invokes_history_notes_tools` 比较 history/notes 后端收到的明文查询和写入参数。

## 上游等价实现后清理

上游统一使用明文工具参数后，删除重复补丁和 fork 专属测试、对应 CI 命令、本 ADR、README 索引及 OVERLAY 条目，并同步修改 ADR 0002。旧协议记录的读取不在本次迁移范围内。
